ANNIE OS MAKER
==============

Makes Annie OS (Arch Linux with KDE Plasma, Steam, Firefox and Oliver) on
this computer and saves it in your Downloads folder, ready to use: no
installer, no disk to erase. It never asks for a password.

It saves two files in Downloads:
  annie-os-<date>-x86_64.qcow2   Annie OS itself, ready to use. Open it in
                                 GNOME Boxes: click +, "Install from File",
                                 pick this file.
  annie-os-<date>-x86_64.iso     the installer ISO, if you'd rather install
                                 Annie OS onto a virtual disk.

The first time Annie OS starts it logs in by itself and asks you for a
password (your user name is "annie") and where you are, for the clock.
After that, you log in with that password.

For Linux and SteamOS (in desktop mode), on a 64-bit Intel or AMD computer.

You need:
  - the internet (it downloads about 2.5 GB from Arch Linux)
  - 30 GB free in your home folder
  - 20 minutes to an hour

The first time you start it, it installs itself into your Downloads folder
(Downloads/Annie OS Maker) by itself, without asking, adds "Annie OS Maker"
to your apps menu, and saves the Annie OS ISOs it makes in Downloads.
After that, start it from there or the apps menu; you can delete the folder
you unpacked.
Everything it uses stays in "Annie OS Maker": the Arch Linux it builds with
(in work/, about 5 GB) and work/last-build.log. To free the space, delete
"Annie OS Maker"/work.

It uses the Arch Linux it already has instead of downloading it again: the
one in work/ (or one an older Maker left in ~/.cache/annie-os-maker, which
it moves over), else an Arch Linux bootstrap file in Downloads
(archlinux-bootstrap-....-x86_64.tar.zst). Only if there's none does it
download the bootstrap, into Downloads.

1. Unpack Annie-OS-Maker.tar.gz (right-click it, Extract, or "Extract
   archive here").

2. Open the "Annie OS Maker" folder and double-click "Annie OS Maker".
   If it asks, choose "Execute" or "Continue"; on some desktops you
   right-click it and choose "Allow Launching" first.
   Or, in a terminal:  cd "Annie OS Maker" && ./annie-os-maker

3. A terminal window shows what it is doing. If a download fails it tries
   again by itself (three times). When it finishes, Annie OS is in
   Downloads: annie-os-<date>-x86_64.qcow2

4. In GNOME Boxes: click +, choose "Install from File", and pick
   annie-os-<date>-x86_64.qcow2. Give it 4 GB of memory or more.

IF IT DOESN'T WORK
Everything it printed is saved in Annie OS Maker/work/last-build.log.
Run it again: it carries on from what it already downloaded.
To free the space it used, delete Annie OS Maker/work.
