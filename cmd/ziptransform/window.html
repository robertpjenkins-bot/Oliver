Zip Transform

Turn an MCreator project ZIP into a mod .jar

Where is MCreator?

Zip Transform builds with the MCreator on this computer — its build files, its Java and the Minecraft files it already downloaded — and could not find it. Enter the folder you unpacked it to.

Drop your MCreator project ZIP here

or

Make it in MCreator from the File menu: Export workspace to a shareable ZIP… — or Export to a shareable ZIP (with run dir)… to bring your worlds along.

Include your world?

The world goes inside the jar. Anyone who starts Minecraft with the mod installed finds it in their world list.

This ZIP has no worlds in it. To bring one along, export again in MCreator with File → Export to a shareable ZIP (with run dir)… and drop that ZIP here.
