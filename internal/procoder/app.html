Pro Coder

A launcher with three coders in it.

Scratch and MakeCode Arcade are websites. Pro Coder opens them with their address on show, and an Exit button to come back here. Some sites refuse to run inside another app; when that happens Pro Coder says so and opens them in a window of their own instead.

CCP is built in. Its blocks are Scratch's blocks and MakeCode Arcade's game blocks in one palette, with a few that belong to neither. It runs without the internet, and can export a finished game as a single HTML file.

Convert turns a project address into an HTML file or a Linux AppImage.
